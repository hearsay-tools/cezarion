Connect to a server

Open your remote Cezarion cockpit. Sign in using the server’s own login page. No local Node.js or agents are needed.

HTTPS is required. For an SSH tunnel, use http://127.0.0.1:PORT. The remote window has no access to native app commands. Sessions are temporary; closing the window signs out.

Use a same-origin web login, or an authenticated SSH tunnel for Basic-Auth-only hosts. Cross-site login redirects are blocked.
