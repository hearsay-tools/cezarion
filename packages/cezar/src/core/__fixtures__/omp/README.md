# OMP (Oh My Pi) RPC fixtures

Pinned to OMP **v18.4.11** (`can1357/oh-my-pi` tag `v18.4.11`, `c0b3937e81e6`). Frame shapes
follow, at that tag:

- `docs/rpc.md`: framing, `ready`, responses, the `prompt` payload, Yield vs settled
  (`agent_end.yielded`, `prompt_result`, `session_settled`), `set_event_filter`
  `messageUpdates: "delta"`, subagent subscriptions.
- `packages/coding-agent/src/modes/rpc/rpc-types.ts`: `RpcPromptResultFrame`,
  `RpcSessionSettledFrame`, `RpcReadyFrame`, `RpcSubagentLifecycleFrame`,
  `RpcSubagentEventFrame`, the failure response (`error` is a string).
- `packages/coding-agent/src/modes/rpc/rpc-subagents.ts` and `packages/wire/src/index.ts`:
  `SubagentLifecyclePayload {id, agent, description?, status, sessionFile?, parentToolCallId?,
  index}`; `subagent_event {payload: {id, event: AgentSessionEvent}}`.
- `packages/coding-agent/src/session/agent-session-events.ts` and
  `packages/agent/src/types.ts`: `agent_end {isTerminal?, yielded?, awaitingAsyncWork?}`,
  `auto_retry_*`, `notice`, `tool_execution_*`, `message_*`.
- `src/edit/index.ts` `aggregateDetails`: edit result `details {path, oldText, newText}` for one
  file, `{perFileResults[]}` for several. Default `edit.mode` is `hashline` (`src/edit/settings.ts`),
  whose args are `{input}`.
- `src/tools/todo.ts` `TodoTool.execute`: result `details {op, phases[].tasks[]{content, status},
  storage}`; statuses `pending | in_progress | completed | abandoned | blocked`.
- `src/task/types.ts`: `task` single form `{agent, task, solutionSpace, name?}` and batch form
  `{context, tasks[]}`.

## Provenance: observed versus constructed

**Observed.** The first eight lines of `rpc-lifecycle.ndjson` were recorded from the real
v18.4.11 binary on 2026-10-05 (`omp --mode rpc`, no user config, `get_state`, then
`set_steering_mode all`, `set_subagent_subscription events`, `set_event_filter {events: null,
messageUpdates: "delta"}`):

| Line | Frame | Edits to the recording |
|---|---|---|
| 1 | `ready` | none |
| 2–4 | unsolicited `extension_ui_request` (`setWidget`), `advisor_cost_changed`, `available_commands_update` | `commands` trimmed from 49 entries to 2 |
| 5 | `get_state` response (`id: "s1"`) | `systemPrompt` and `dumpTools` removed; the `sessionFile` directory rewritten to a neutral home |
| 6–8 | `set_steering_mode`, `set_subagent_subscription`, `set_event_filter` responses | none |

The three unsolicited frames arrive in plain `--mode rpc` before any prompt. The mapper ignores
them (and every `set_*` acknowledgement); the golden test pins that they emit nothing.

**Constructed.** Everything after line 8 of `rpc-lifecycle.ndjson`, and every line of
`rpc-edit-todo`, `rpc-subagents` and `rpc-retry`, is **source-derived**: no live model turn was
possible on the recording host (no OMP provider login), so no turn frame here is a capture.
Text, paths, ids, tool arguments, outputs and usage numbers are synthetic; the hashline `input`
strings are placeholders, not a claim about the hashline grammar. Specific choices:

- The mock frames emitted after `session_settled` (used by the R15 regression) are constructed: real OMP settles only when `!hasPendingAsyncWork`, so the wire never sends them. They are kept as a stricter robustness test.
- Session `message_update` frames use the delta projection the runner opts into
  (`{type, messageId, message: {role}, assistantMessageEvent}` with no `partial`); `subagent_event`
  payloads keep the full snapshot, as `rpc.md` says the projection does not apply to them.
- A turn ends with `agent_end {yielded: true}`, `prompt_result`, then `session_settled`.
  `rpc-retry` has a failed attempt (`message_end stopReason: "error"`), a non-terminal
  `agent_end {yielded: false}`, `auto_retry_start`, then a successful attempt.
- `rpc-subagents` sends two child frames of `RpcMapper` before its `subagent_lifecycle`, to
  exercise the early-event buffer. Whether v18.4.11 can emit a child event ahead of its lifecycle
  frame is not established; the mapper handles both orders.
- The batch's `Tests` agent ends `aborted` with an open text block.

## Expected files

Each `*.expected.json` was generated by replaying its `.ndjson` through `mapOmpRpcMessage`
(after `ompTurnStarted`, as the runner opens the turn when it writes the prompt), then reviewed
event by event against the spec's wire-mapping table and the sub-agent rules. The golden test
compares the replay to them exactly.
